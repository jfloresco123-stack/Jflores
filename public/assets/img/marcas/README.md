# Iconos de marcas

Logotipos vectoriales (SVG 24×24) organizados por categoría de equipo:

| Carpeta | Marcas |
|---|---|
| `celulares/` | Android, Apple, Honor, Huawei, Motorola, OPPO, Samsung, vivo, Xiaomi |
| `computo/` | Acer, ASUS, Dell, HP, Lenovo, MSI, Toshiba |
| `impresoras/` | Epson |
| `audio-video/` | JBL, LG, Sony |
| `electronica/` | Arduino, Bambu Lab, Creality, Raspberry Pi |

- **Fuente:** [Simple Icons](https://simpleicons.org) v16.36.0 (licencia CC0 para los archivos SVG). Cada archivo lleva el color oficial de la marca en el atributo `fill`.
- **Índice:** `marcas.json` registra el nombre, el color y la ruta de cada icono. La web lo lee para mostrar la franja de marcas.
- **Agregar una marca:** descarga `https://cdn.jsdelivr.net/npm/simple-icons@latest/icons/<slug>.svg`, añade `fill="#HEX"` a la etiqueta `<svg>`, guárdalo en la carpeta que corresponda y regístralo en `marcas.json`.
- **Marcas sin icono en Simple Icons** (Windows, Canon, Brother): se retiraron del proyecto a pedido de sus dueños. No las agregues sin revisar sus condiciones de uso de marca.

> Los logotipos son marcas registradas de sus respectivos dueños. Se usan solo para indicar con qué equipos trabajamos (uso nominativo). No implican afiliación ni patrocinio.
